❓ PostManage 使用说明书与架构文档

1. 快速入门与核心功能

PostManage v2.0 是一款基于 Go 纯标准库打造的单二进制高性能 API 调试与压测平台。支持完整的 REST 接口测试、全链路网络耗时瀑布流拆解、高并发性能压测与页面接口智能嗅探。

2. 全链路网络耗时拆解 (Waterfall)

基于 Go 底层 net/http/httptrace 纳米级精确测量每次请求在 DNS 查询、TCP 握手、TLS 密钥交换、请求发送、等待首包 (TTFB) 及内容下载等全流程的耗时与百分比。

3. 极简高并发性能压测

摆脱 Python GIL 限制，依靠 Go 原生协程池单机轻松支撑万级高并发。秒级滑动统计平均 TPS 与峰值 TPS，精准计算 P50/P90/P99 延迟分位数并给出性能瓶颈诊断。

4. 页面接口智能嗅探与健康巡检

输入任意 Web 页面 URL，自动获取 HTML 源码及关联外链 JS 脚本，多引擎正则并行挖掘接口路径并并发发起探测，以红黄绿大盘呈现健康状态。

5. 全局请求头与优先级覆盖

全局请求头在所有请求中生效。若单个请求单独配置了同名 Key（不区分大小写），则以单个请求的配置优先覆盖！
